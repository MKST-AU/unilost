# UniLost application

This folder contains the Next.js application. Start with the [root README](../README.md) for the public demo, team responsibilities, local setup and limitations.

Run application commands here, after following the setup instructions:

```sh
npm run dev       # Configured MongoDB, localhost:3000
npm run demo      # Temporary local database, localhost:3217
npm run verify    # Lint, types, build and automated tests
```

Stop the local demo before verification so port 3217 is free. Browser tests require Google Chrome.
