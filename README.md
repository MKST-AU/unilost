# UniLost — Campus Lost & Found Management System

UniLost helps a campus community report lost or found items, browse item reports, submit ownership claims, and record returned property.

## Team members

- Myo Kyi Sim Thar
- Myat Zay Hein

## Stack

- Next.js
- MongoDB
- REST API route handlers

## Development

The shared architecture, data model, API contract, and Git workflow are in [PROJECT.md](PROJECT.md).

### Local setup

1. Install Node.js LTS (includes npm).
2. Create the Next.js starter application and install dependencies.
3. Copy `.env.example` to `.env.local` and set the MongoDB connection string.
4. Run `npm run dev`.
